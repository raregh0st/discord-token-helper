# Discord Token Helper

**by [raregh0st](https://github.com/raregh0st)**

Copy the auth token of the Discord account you are already logged in as. Everything —
instructions, the bookmarklet, the console snippet, troubleshooting and how it works —
lives in [`index.html`](./index.html), which is also the live page:

### → https://raregh0st.github.io/discord-token-helper/

> Never share your token. Self-bots violate Discord's Terms of Service and can get your
> account terminated. Use this only on your own account.
